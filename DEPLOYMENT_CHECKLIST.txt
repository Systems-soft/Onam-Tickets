🚀 DEPLOYMENT STEPS

Step 1: Push to Git
─────────────────────────────────────────────────────────────────────────────
  git add .
  git commit -m "Prepare for Vercel deployment"
  git push origin main

Step 2: Deploy to Vercel
─────────────────────────────────────────────────────────────────────────────
  Option A (CLI):
    npm install -g vercel
    vercel

  Option B (Web):
    1. Go to https://vercel.com/new
    2. Connect GitHub repository
    3. Click "Deploy"

Step 3: Set Environment Variables in Vercel
─────────────────────────────────────────────────────────────────────────────
  1. Vercel Dashboard → Project Settings → Environment Variables
  2. Add: STRIPE_SECRET_KEY (from above)
  3. Add: STRIPE_WEBHOOK_SECRET (from above)
  4. Click "Save"
  5. Click "Redeploy" to apply variables

Step 4: Configure Stripe Webhook
─────────────────────────────────────────────────────────────────────────────
  1. Stripe Dashboard → Developers → Webhooks
  2. Click "Add endpoint"
  3. Endpoint URL: https://your-vercel-domain.vercel.app/api/stripe-webhook
  4. Events to send: checkout.session.completed
  5. Click "Add endpoint"
  6. Copy "Signing Secret" 
  7. Add to Vercel as STRIPE_WEBHOOK_SECRET
  8. Redeploy Vercel project

Step 5: Test the Deployment
─────────────────────────────────────────────────────────────────────────────
  1. Visit https://your-vercel-domain.vercel.app/
  2. Add ticket to cart
  3. Click "Reserve tickets"
  4. Stripe payment page should open
  5. Test with card: 4242 4242 4242 4242, Expiry: 12/34, CVC: 567
  6. Complete payment
  7. Success page should appear
